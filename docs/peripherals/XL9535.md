# XL9535 I/O expander

The XL9535 is a 16-pin I²C GPIO expander. It adds digital pins that other peripherals can use,
for example to drive relays for valves. It publishes no telemetry of its own.

## Hardware support

The XL9535 connects to an I²C bus of Ugly Duckling, given by its `sda` and `scl` pins.

## Configuration

Add a `multiplexer:xl9535` peripheral, then refer to its pins as `<name>:<pin>`, where `<pin>`
is `0` to `15`. For example, on MK6, a valve driven by pin 0 of an expander named `relay`:

```json
{
  "peripherals": [
    {
      "name": "relay",
      "type": "multiplexer:xl9535",
      "params": {
        "sda": "C1",
        "scl": "C4",
        "address": "0x20"
      }
    },
    {
      "name": "valve-1",
      "type": "valve",
      "params": {
        "pin": "relay:0"
      }
    }
  ]
}
```

| Parameter | Default | Meaning |
| --- | --- | --- |
| `sda`, `scl` | (required) | I²C pins of the bus the expander is on |
| `address` | (required) | The expander's I²C address, as a string, e.g. `"0x20"` |
| `clkSpeed` | `400` | I²C clock in kHz |

Template: [`multiplexer-mk6.json`](../../config-templates/multiplexer-mk6.json).

## Using the expander's pins

The expander registers its 16 pins as `<name>:0` to `<name>:15` when it is created. Pins 0–7 are
the chip's port 0, pins 8–15 its port 1.

- List the expander before the peripherals that use its pins. Peripherals are created in the
  order they appear, and a pin name that isn't registered yet fails with `Unknown pin`.
- Only parameters that accept any pin can take an expander pin: a valve's `pin`, and the
  `disablePin` of an HW-390 soil moisture sensor. Parameters that need a pin of the
  microcontroller (pulse counting, analog reads, I²C) report `Unknown internal pin`.

Every pin is an input until a peripheral sets it as an output.

## Limitations

- No pull-up or pull-down: a peripheral that asks for one gets a plain input.
- A failed I²C read returns `0` (low) for the pin and logs a warning; a failed write is only
  logged.
- No interrupts: pins are read only when a peripheral asks.
