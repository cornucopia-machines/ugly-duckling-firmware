# HW-390 soil moisture sensor

The HW-390 is an analog soil moisture sensor: it outputs a voltage that Ugly Duckling reads with
the ESP32's ADC and converts to a moisture percentage using your calibration.

The type is `soil:hw390`. `environment:soil-moisture` is the same peripheral under its old name,
kept so that existing configurations keep working; use `soil:hw390` in new ones.

## Connection

Connect the sensor's output to an ADC-capable pin. Optionally, a second pin can switch the sensor
off between readings (`disablePin`).

| Ugly Duckling | Sensor output | Disable pin |
| --- | --- | --- |
| MK6, MK7, MK8 | `A1` (in the templates) | — |
| MK9 | `ISOILML` | `NENSOILM` |

## Configuration

```json
{
  "peripherals": [
    {
      "name": "soil-moisture-sensor",
      "type": "soil:hw390",
      "params": {
        "pin": "ISOILML",
        "disablePin": "NENSOILM",
        "air": 3017,
        "water": 1105
      }
    }
  ]
}
```

| Parameter | Default | Meaning |
| --- | --- | --- |
| `pin` | (required) | ADC-capable pin the sensor's output is on |
| `disablePin` | (none) | Pin that switches the sensor off while high. Leave it out if the sensor is always powered |
| `enableDelay` | `100` | Milliseconds to wait after enabling the sensor before reading it |
| `air` | `3000` | Raw ADC reading in dry air (0 %) |
| `water` | `1000` | Raw ADC reading in water (100 %) |
| `alpha` | `1.0` | Smoothing factor (0–1) of an exponential moving average over readings. `1` means no smoothing; smaller values smooth more |

Templates: [`plot-controller-mk9-hw390.json`](../../config-templates/plot-controller-mk9-hw390.json),
and the `*-fully-equipped.json` templates for MK6–MK8, which feed it into a
[Kalman filter](KalmanSoilMoisture.md).

### Calibration

The defaults are only a starting point; measure `air` and `water` for each sensor. The raw reading
is logged at verbose level (`Soil moisture value: ...`). Drier soil gives a higher raw reading, so
`air` is normally larger than `water`.

## Telemetry

| Feature | Unit | Value |
| --- | --- | --- |
| `moisture` | % | `(raw − air) × 100 / (water − air)`, smoothed by `alpha` |

The value is not clamped, so it can go below 0 % or above 100 % outside the calibration range.

## Behavior

With `disablePin` set, the sensor is off (pin high) from startup and between readings. For each
reading the pin goes low, the device waits `enableDelay`, reads the ADC, and sets the pin high
again. A new reading is taken at most once a second.

If the ADC read fails, the device logs `Failed to read soil moisture value from pin ...` and keeps
the last value; before the first good reading the value is `null`.

A pin that can't do ADC fails the peripheral at startup with `Pin ... cannot be used for analog
reads`.

## Limitations

- No temperature reading. For temperature-compensated moisture, pair it with a soil temperature
  sensor through a [Kalman filter](KalmanSoilMoisture.md).
