# TSL2591 light sensor

The TSL2591 measures ambient light in lux. It connects to an I²C bus. Like every light sensor, it
can drive the chicken door function.

## Configuration

```json
{
  "peripherals": [
    {
      "name": "light-sensor",
      "type": "light-sensor:tsl2591",
      "params": {
        "sda": "SDA",
        "scl": "SCL"
      }
    }
  ]
}
```

| Parameter | Default | Meaning |
| --- | --- | --- |
| `sda`, `scl` | (required) | I²C pins the sensor is on |
| `measurementFrequency` | `1` | Seconds between readings |
| `latencyInterval` | `5` | Seconds of readings to average over |

The TSL2591 has a single address, 0x29, and the driver sets its own I²C clock: `address` and
`clkSpeed` are ignored.

## Telemetry

| Feature | Unit | Value |
| --- | --- | --- |
| `light` | lx | Ambient light, averaged |

## Behavior

The sensor runs at medium gain with a 300 ms integration time. A background task reads it every
`measurementFrequency` seconds, and the reported value is the average of the last
`latencyInterval` / `measurementFrequency` readings (5 by default). A failed reading is skipped,
so the average keeps its previous value. Before the first good reading the value is `0`.

If the sensor doesn't answer at startup, the peripheral fails to start.

## Limitations

- Gain and integration time are fixed.
- `latencyInterval` must be at least `measurementFrequency`.
- One sensor per I²C bus.
