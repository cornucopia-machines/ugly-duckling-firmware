# DS18B20 soil temperature sensor

The DS18B20 is a digital temperature sensor on a 1-Wire bus. Ugly Duckling uses it to measure soil
temperature.

## Wiring

Connect the sensor's data line to a GPIO, and fit a 4.7 kΩ pull-up resistor between the data line
and the sensor's supply. The firmware turns the pin's internal pull-up off and relies on the
external resistor.

The `*-fully-equipped.json` templates for MK6, MK7 and MK8 use pin `A2`.

## Configuration

```json
{
  "peripherals": [
    {
      "name": "soil-temperature",
      "type": "environment:ds18b20",
      "params": {
        "pin": "A2"
      }
    }
  ]
}
```

| Parameter | Default | Meaning |
| --- | --- | --- |
| `pin` | (required) | The 1-Wire data pin |
| `address` | (search) | The sensor's 64-bit 1-Wire address, as 16 hex digits. Without it the firmware searches the bus at startup and uses the first sensor it finds |

Templates: [`plot-controller-mk6-fully-equipped.json`](../../config-templates/plot-controller-mk6-fully-equipped.json),
[`plot-controller-mk7-fully-equipped.json`](../../config-templates/plot-controller-mk7-fully-equipped.json),
[`plot-controller-mk8-fully-equipped.json`](../../config-templates/plot-controller-mk8-fully-equipped.json).
These feed the temperature into a [Kalman filter](KalmanSoilMoisture.md) together with an
[HW-390](HW-390.md) moisture sensor.

## Telemetry

| Feature | Unit | Value |
| --- | --- | --- |
| `temperature` | °C | Soil temperature |

## Behavior

Each reading starts a conversion, waits 750 ms for it to finish, then reads the result. A new
reading is taken at most once a second.

If a reading fails, the device keeps the last good value (`null` before the first one) and logs
the error at debug level only (`Error measuring DS18B20 temperature` or `Error reading DS18B20
temperature`).

Without `address`, the peripheral fails at startup with `No DS18B20 sensors found on bus` if the
search finds nothing.

## Limitations

- One sensor per peripheral. Without `address`, a peripheral always uses the first sensor the
  search finds, so on a bus with more than one sensor, set `address`.
